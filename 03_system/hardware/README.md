# Minimal Hardware Demonstrator

**Purchase status:** Hold until Gate G1.

## Candidate parts

- One ESP32 development board
- One INA219 low-voltage voltage/current sensor
- One ATECC608 secure-element breakout
- Breadboard/jumper wires
- Safe 5–12 V supply and small load

## Safety

Paper 1 uses low-voltage DC only. Do not connect the prototype directly to building mains electricity.

## Claims supported

- Physical measurement acquisition is demonstrated.
- Device identity key is hardware protected.
- Observations can be signed at the acquisition node.

## Claims not supported

- Correct or uncompromised ESP32 firmware
- Hardware-attested measurement execution
- Accredited calibration
- Building-grade metering accuracy
- Tamper-resistant physical installation

## Before purchasing

- Inventory existing equipment.
- Confirm the Week-1 novelty gate.
- Confirm total delivered cost under the approved cap.
- Prefer borrowing a reference meter or multimeter.
