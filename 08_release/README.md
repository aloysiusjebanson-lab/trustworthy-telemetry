# Reproducibility Release

The final release should contain:

- Archived source revision
- Environment and dependency lock files
- Valid example claim bundle
- Corrupted example bundles
- Independent verifier
- One-command reproduction instructions
- Experiment configurations and raw results
- Analysis scripts and generated figures/tables
- Hardware bill of materials, wiring, firmware, and photographs if used
- Data/source licenses and citation instructions
- Statement of known limitations and non-established properties

The release must not contain `09_confidential_commercial`, invention hypotheses, patent analysis, customer-discovery records, or other non-public commercialization material.

The release must be tested from a clean environment by someone other than the primary implementer before submission.
