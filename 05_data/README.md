# Research Data

Planned layout:

```text
05_data/
├── raw/          # append-only original acquisition or source files
├── interim/      # deterministic intermediate data
├── processed/    # analysis-ready outputs generated by code
└── external/     # versioned public datasets and emission-factor inputs
```

## Rules

- Never manually edit files in `raw`.
- Record source URL, access date, license, and checksum for external data.
- Generate interim and processed data through scripts.
- Do not commit sensitive building or occupant data.
- Large files should be archived outside Git with checksums and retrieval instructions.
